---

The process of an object becoming brighter when it is moving *towards* the Earth. This is *in conjunction* with Doppler shift. This brightness increase can be attributed to the fact that, for a star moving *towards* the earth, from the perspective of the earth, a `clock' placed near the star would run *faster* than one on earth. If photons are emitted at a set rate on this `clock' it would be faster, when scaling the star `clock' to the earth one, it would be faster, meaning that the interval between received photons would be faster, and thus the object would appear brighter.
